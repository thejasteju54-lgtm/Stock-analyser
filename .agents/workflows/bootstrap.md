## Do Not Code Yet

Do not begin application implementation during the initial audit.

First determine:

1. What already exists.
2. What is missing.
3. Whether the architecture is consistent.
4. Whether dependencies are necessary.
5. Whether existing code conflicts with the planned architecture.
6. What Phase 0 requires.
7. What risks could affect the project.

## Validation

Check that:

- AGENTS.md exists
- PRD.md exists
- Architecture.md exists
- Rules.md exists
- Design.md exists
- Phases.md exists
- Memory.md exists
- .agents/rules exists
- .agents/skills exists
- .agents/workflows exists

Inspect whether required skills contain valid SKILL.md files.

## Output

Create a concise repository audit.

Include:

- Current state
- Existing technology
- Missing components
- Architecture concerns
- Testing status
- MCP/skills status
- Recommended next step

## Memory

Update Memory.md with:

- current phase
- audit status
- discovered architecture
- important risks
- next action

## Completion Rule

Do not claim bootstrap is complete until the repository has been inspected and the audit is documented.
