# QA Verification Skill

## Purpose

Use this skill to check the accuracy, consistency, and reliability of financial research outputs before final delivery.

## Verification Checklist

Check for:

- Unsupported claims
- Invented numbers
- Wrong financial periods
- Standalone vs consolidated mismatch
- Conflicting data
- Missing source references
- Outdated information
- Calculation errors
- Valuation inconsistency
- Overconfident language
- Unclear assumptions
- Missing risks

## Rules

Do not approve an output if material claims lack evidence.

Flag every unverifiable number.

Confirm that conclusions follow from the evidence.

## Output Format

Provide:

- Pass/fail status
- Issues found
- Severity of each issue
- Suggested correction
- Missing evidence
- Final readiness status

## Severity Levels

- Critical: Could materially mislead the user
- High: Important accuracy or sourcing problem
- Medium: Needs clarification
- Low: Minor wording or formatting issue

## Final Rule

If the research cannot be verified, say:

"Not ready for final use. Verification gaps remain."
