# Valuation Analysis Skill

## Principle

Valuation must be sector-aware.

First classify the business.

Then select appropriate metrics.

## Required Analysis

Compare:

current valuation
historical valuation when available
peer valuation when verified
growth
profitability
balance-sheet quality

## Critical Rule

Never invent historical or peer multiples.

If unavailable:

"Peer/historical valuation data not verified."

Cheap
Fair
Expensive
Extreme

Then explain why.

Always test whether the valuation assumes unrealistic growth.
