# Technical Analysis Skill

## Purpose

Use this skill when analyzing stock price action, chart patterns, trend, support, resistance, volume, momentum, or technical indicators.

## Rules

Technical analysis must be based on actual price and volume data.

Never invent price levels, indicators, moving averages, RSI, MACD, volume, breakout levels, or chart patterns.

If live or verified market data is unavailable, state:

"Technical analysis unavailable without verified price and volume data."

## Analysis Checklist

When data is available, review:

- Current price
- Trend direction
- Support zones
- Resistance zones
- Volume behavior
- Moving averages
- Momentum indicators
- Breakout or breakdown levels
- Risk levels
- Invalidating conditions

## Output Format

Provide:

- Trend summary
- Key support
- Key resistance
- Momentum view
- Volume confirmation
- Bullish case
- Bearish case
- Risk management notes

## Limitation

Technical analysis is not investment advice and must be treated as probability-based, not certainty-based.
