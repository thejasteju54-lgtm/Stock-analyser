# Source Hierarchy

## Purpose

Define how the Stock Analyzer prioritizes conflicting information.

## Tier 1 — Primary Audited Sources

Highest priority for historical financial information:

- audited financial statements
- annual reports
- statutory filings
- official exchange filings
- official regulatory filings

## Tier 2 — Official Company Sources

- investor presentations
- official results
- official company announcements
- official earnings releases
- official concall transcripts
- official management commentary

## Tier 3 — Verified Market Data

Use reputable market-data providers for:

- historical prices
- volume
- market capitalization
- valuation metrics

Verify methodology where possible.

## Tier 4 — Reputable Financial Media

Use for:

- current events
- industry developments
- management events
- contextual information

Examples may include reputable Indian financial publications.

## Tier 5 — Secondary Sources

Use cautiously.

Examples:

- financial blogs
- forums
- social media
- unsourced databases

These should not override primary evidence without strong justification.

## User-Provided Screenshots

Screenshots are useful evidence but may contain:

- stale data
- OCR errors
- incomplete context
- cropped information

Treat them as lower-confidence than authoritative underlying filings when both exist.

## Conflict Resolution

When sources conflict:

1. Identify conflict.
2. Compare source quality.
3. Check reporting period.
4. Check accounting basis.
5. Check units.
6. Check restatement status.
7. Determine whether both values are actually measuring different things.
8. Resolve only when evidence supports resolution.
9. Otherwise mark as conflicting.

## Current Information

Current news should always retain:

- publication date
- source
- event
- relevance

Do not present old information as current.

## Core Rule

Source quality must influence confidence, but a lower-tier source can still be useful when primary information is unavailable.
